# Løvatlas fra eieren

Ark på hvit bakgrunn etter de gamle promptene (`docs/prompter-3.md`, slettet 19. oktober; nye i `docs/prompter/`): klyngene skjæres ut mot det hvite (som `tools/textures/leaf_atlas.py`) og blir alfakort til trærne, buskene og gresset.

| Fil | Innhold |
|---|---|
| `leaves_oak` | 16 eikeløvklynger |
| `leaves_birch` | 12 hengende bjørkeklaser |
| `needles_spruce` | 8 grankvister |
| `leaves_bush` | 12 buskklynger: hassel, einer, nype og bjørnebær |
| `grass_flowers` | 20 tuster: gress i fem høyder og engblomster |

Forbildene `tree_ref.jpeg` (eik, bjørk, gran, furu, rogn og dødt tre) og `bush_ref.jpeg` ligger i `../props/ref/`.
