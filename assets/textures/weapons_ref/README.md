# Forbilder for våpen, skjold, rustninger og armene

Fra eieren etter de gamle promptene (`docs/prompter-3.md`, slettet 19. oktober; nye i `docs/prompter/`). Våpnene og skjoldene er tegnet rett forfra og fyller bildet, så de males rett på modellene.

- `weapon_sword/axe/dagger/mace/spear.jpeg`: ett våpen (eller to) rett fra siden.
- `*_rarity.jpeg`: samme våpen i fire utgaver (common, uncommon, rare, legendary) med rammer og navnelapper – rammene og teksten skjæres bort. Legendary gløder.
- `shield_round/heater/tower_front.jpeg` og `shield_back/heater_back/tower_back.jpeg`: for- og baksider.
- `armour_sets.jpeg`, `armour_sets2.jpeg`: fire rustningssett på stativ.
- `arms_fp.jpeg`, `arms_fp2.jpeg` (håndbaken), `arms_fp2_palm_side.jpeg` (håndflaten): armene i førsteperson i fire utgaver.
