# Forbildene til inventaret

Arkene fra eierens bildegenerator etter `docs/prompter-3.md`, hvert med 3 × 3 ting. Formene modelleres i Blender etter dem, og flatene får de malte teksturlagene (se `docs/ny-alt.md`).

| Ark | Innhold |
|---|---|
| `furniture_a` | seng, briks, vugge, langbord, rundbord, benk, krakk, stol og vaskestativ |
| `furniture_b` | kiste, reisekiste, hylle med krukker, skap, knaggrekke med sleiver, trau, tønne, ankeret og kurv |
| `hearth` | ildsted, gryte på trefot, grytekrok, spidd, bakerovnsdør, vedstabel, kinne, håndkvern og løk med urter. Arket har navnelapper under tingene. |
| `tableware` | treboller, krukke og kopper, tinnkrus, brød og ost, fisk på fat, eplekurv, stuing på fjøl, lys og ankeret med tapp |
| `apothecary` | krukkehylle, morter, skålvekt, urtebunter, skrivepult, bokstabel, rullestativ, lesepult med lenkebok og lysestake |
| `textiles` | ryer, lappeteppe, saueskinn, stripet veggteppe, billedvev med hjort, duk og tre faner (rød med kors, blå med løve, grønn med tre). Fanene og veggteppene henger nesten rett forfra og kan skjæres ut som bilder. |
| `workshop` | ambolt på stubbe, esse med blåsebelg, tangstativ, kjølekar, slipestein, høvelbenk, verktøybrett, jernstenger og hesteskorekke |
| `dng_grav` | sarkofag med ridder, knust kiste med bein, hodeskallehaug, lysklynge, kandelaber, urne, gravnisje med lik, offerkiste og veltet gravstein |
| `dng_kloakk` | rist over sluk, utløpsrør, sluseluke med hjul, halvsunket tønne, slimet søppel, plankegang, rusten kjetting, mosegrodd søyle i vann og rotterede |
| `dng_gruve` | malmvogn, rett og buet skinne, tømmerstiver, vinsj, gruvelykt, malmhaug, hakke og spade, krystallklynge (stalagmittene mangler) |
| `dng_mekanikk` | spak, gitter, eikedør med slå, fallem, stige, trykkplate, pilhull, pendel og hvilestedet (alter med lysestake) |
| `dng_borg` | riddarstatue, fillete fane, rustning på stativ, glødepanne, spydstativ, knust trone med glitch, brønn, falt lysekrone og gargoyle |
| `dng_kjerne` | søyle som blir plast, svevende pikselkuber, sprukken statue med lys, plaststein, plastkasse, pikselsøyle, dør som går i oppløsning, krystaller og en dam med kuber |
| `clutter_dungeon` | knust tønne, bein og hjelm, råtten sekk med mynter, brukket spyd og skjold, falt hylle med knuste krukker, rasmasse med hakke, lenker og jern, veltet kandelaber og skjelett mot veggen |
| `clutter_market` | kålkasse, tønne med saltfisk, tøyruller, pølsestativ, eggkurv, oster, melsekk, skobenk og hønsebur |
| `animals_ref` | ku, sau, hest, gris, geit og hund (forbilder for dyrene) |
| `clutter_town` | knust kasse, kornsekker, tau og bøtte, knust hjul, krukker, ved og øks, trillebår, hestesko og spann, filler og kost |
| `tree_ref` | eik, bjørk, gran, furu, rogn og dødt tre (forbilder for trærne) |
| `bush_ref` | hassel, einer, nype, bjørnebær, bregne og siv |
| `items1`–`items4` | fire ark med småting i 3 × 3 (flasker, lykt, støvler, krus, kikkert, kiste, bøker, urter, hjelm og sverd, edelstener, gryte, mugge, speil, nøkler …): forbilder for inventar, kister og butikkvarer |
