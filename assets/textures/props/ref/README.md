# Forbildene til inventaret

Arkene fra eierens bildegenerator etter `docs/prompter-3.md`, hvert med 3 × 3 ting. Formene modelleres i Blender etter dem, og flatene får de malte teksturlagene (se `docs/ny-alt.md`).

| Ark | Innhold |
|---|---|
| `furniture_a` | seng, briks, vugge, langbord, rundbord, benk, krakk, stol og vaskestativ |
| `furniture_b` | kiste, reisekiste, hylle med krukker, skap, knaggrekke med sleiver, trau, tønne, ankeret og kurv |
| `hearth` | ildsted, gryte på trefot, grytekrok, spidd, bakerovnsdør, vedstabel, kinne, håndkvern og løk med urter. Arket har navnelapper under tingene. |
| `tableware` | treboller, krukke og kopper, tinnkrus, brød og ost, fisk på fat, eplekurv, stuing på fjøl, lys og ankeret med tapp |
