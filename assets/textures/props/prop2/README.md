# Heltegjenstander i to visninger (`prop2`)

Fra eieren etter de gamle promptene (`docs/prompter-gjenstander.md`, slettet 19. oktober; nye i `docs/prompter/`): 3/4 forfra til venstre og 3/4 bakfra til høyre i samme bilde, samme skala, grå bakgrunn uten skygge. Bygges med `sheet2model` (`layout: prop2`).

| Fil | Gjenstand | Prior |
|---|---|---|
| `chest` | kista (lokket lukket) | chest |
| `barrel` | tønna | barrel |
| `well` | brønnen med vinde og spontak | glb/box (brønnhodet sylinder, tak og stolper egne deler) |
| `anvil` | ambolten på stubben | glb (stubbe sylinder + ambolt) |
| `rest_shrine` | hvilestedet: steinalter med lysestake og lysende sprekk | box + lysestake egen del |
| `lever` | spaken i steinsokkel | box + arm |
| `gate` | gitteret (portcullis) | flat gitter (box, tynn) |
| `sarcophagus` | sarkofagen med ridder på lokket | box |
| `cauldron` | gryta med sleiv | revolve |
| `altar` | alteret med rød duk, to lysestaker og relikvieskrin (2528 × 1696, ikke kvadratisk) | box + lysestaker egne deler |

Merk: gitteret er tegnet nesten rett forfra og bakfra, ikke 3/4. Tønna er den samme som i `furniture_b`-piloten, nå i to visninger.
