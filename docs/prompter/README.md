# Promptene (17. oktober)

Alt eieren skal lage med bildegenerator, Veo og TRELLIS, samlet på ett sted. Gå gjennom filene i denne rekkefølgen; innenfor hver fil står det viktigste først.

1. **`teksturer-malt.md`**: de fem underkjente teksturene på nytt (brosteinen, grunnmuren, kjernesteinen, den røde pussen, kryptpussen), så det som mangler for krypttemaene, naturen og byen. Lagres i `assets/textures/painted/<navn>/albedo.png`.
2. **`modeller-trellis.md`**: vertinnen, trærne, buskene, steinene og gresset, dyrene, varene på torget, kryptens pynt og gjenstandene. Bilde → TRELLIS.2 (Resolution 1536, Decimation Target 500000, Texture Size 4096) → send glb-fila med navnet i overskriften.
3. **`ikoner-utstyr.md`** (18. oktober): ett malt ikon per våpen, skjold, rustning og lykta (19 ikoner, 512 × 512), til kortene i inventaret og Skriptoriet. Lagres i `assets/textures/icons/<id>.png`.
4. **`monstre.md`**: alle 27 monstrene i samme stil, med dreieark og teksturark for hvert. Arkene lagres i `assets/textures/monsters/ref/<id>_turn.png` og `<id>_tex.png`.

Filmens prompter står i `docs/film/prompter-innstillinger.md`, og innbyggernes ark i `docs/prompter-folk-3d.md`.

Send filene her i samtalen (enkeltfiler eller zip). Jeg legger dem på plass, bygger dem med verktøyene som står ved hver prompt, og viser deg resultatet før det tas i bruk.
